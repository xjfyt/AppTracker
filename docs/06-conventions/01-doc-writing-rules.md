# 三十一、文档编写规范

## 1、文件头

每个文档文件顶部必须包含引用块，标明对应代码和维护提示：

```markdown
> **对应代码**：`tracker-core/src/agent.rs`
> **维护提示**：修改主循环逻辑时同步更新本文档。
```

## 2、标题层级

| 层级 | 格式 | 示例 |
|------|------|------|
| H1 | `# 一、标题` | `# 一、项目简介` |
| H2 | `## 1、标题` | `## 1、概述` |
| H3 | `### （1）标题` | `### （1）启动流程` |
| H4 | `#### ① 标题` | `#### ① 第一步` |

H1 使用中文数字序号（一、二、三...），H2 使用阿拉伯数字（1、2、3...），H3 使用括号数字（（1）、（2）...），H4 使用圈号（①、②...）。

## 3、文件尾

每个文档文件底部必须包含导航链接：

```markdown
---
- 上一篇：[xx-xxx.md](./xx-xxx.md)
- 下一篇：[yy-yyy.md](./yy-yyy.md)
- 返回索引：[docs/README.md](../README.md)
```

首篇：`上一篇：（无，这是首篇）`
末篇：`下一篇：（无，这是末篇）`

## 4、内容规范

### 语言

- 正文使用中文
- 代码块、API 路径、命令行使用英文
- 技术术语首次出现时附英文原文

### 代码块

使用语言标签标注：

````markdown
```rust
fn example() {}
```

```bash
cargo build
```

```json
{"key": "value"}
```
````

### 表格

API 端点、配置项、数据结构等使用表格展示：

```markdown
| 字段 | 类型 | 说明 |
|------|------|------|
| name | String | 名称 |
```

### 架构图

使用 ASCII art 绘制：

```
┌──────────┐     ┌──────────┐
│  Module A │────→│  Module B │
└──────────┘     └──────────┘
```

- 文件名：`xx-descriptive-name.md`（两位数字前缀 + 连字符分隔）
- 目录名：`xx-descriptive-name/`（两位数字前缀 + 连字符分隔）
- 同一目录下的文件按数字顺序排列
