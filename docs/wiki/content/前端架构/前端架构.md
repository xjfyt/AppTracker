## 简介

AppTracker 前端采用纯 vanilla HTML/CSS/JS 技术栈，无框架依赖，由 Tauri WebView 直接加载。

## 技术选型

| 技术 | 选择 | 理由 |
|------|------|------|
| 框架 | 无（vanilla） | 零构建开销，极小体积 |
| 模块系统 | ES Modules | 浏览器原生支持 |
| CSS 方法论 | CSS 自定义属性 | 设计令牌 + 组件样式 |
| 布局 | CSS Grid + Flexbox | 响应式网格 |
| 实时通信 | WebSocket + Fetch | 事件推送 + REST 调用 |

## 页面布局

```mermaid
graph TB
    subgraph "index.html"
        TOPBAR[顶部栏<br/>品牌 + 工具栏]
        SHELL[应用壳]

    end

    subgraph "SHELL"
        SIDEBAR[侧边标签<br/>当前状态 / 诊断]
        VIEWS[视图栈]
    end

    subgraph "VIEWS"
        OVERVIEW[当前状态视图<br/>三列网格]
        DIAG[诊断视图<br/>两列网格]
    end

    subgraph "OVERVIEW 列"
        COL1[窗口信息<br/>文档路径]
        COL2[浏览器插件 Key<br/>浏览器 Tab<br/>终端<br/>文件管理器]
        COL3[活动统计<br/>截图]
    end

    TOPBAR --> SHELL
    SHELL --> SIDEBAR
    SHELL --> VIEWS
    VIEWS --> OVERVIEW
    VIEWS --> DIAG
```
