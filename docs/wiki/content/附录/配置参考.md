## 简介

AppTracker 的配置主要通过代码中的 `AgentConfig` 结构体和环境变量控制，无需配置文件。

## 配置文件

### 目录结构

```
~/.apptracker/
├── token               # 浏览器扩展鉴权 Token

~/.active_tracker/
├── crash.log           # 崩溃日志（追加写入）
└── shells/
    ├── 1234.cwd        # Shell PID 1234 的 cwd
    ├── 1234.cmd        # Shell PID 1234 的最近命令
    ├── 5678.cwd        # Shell PID 5678 的 cwd
    └── 5678.cmd        # Shell PID 5678 的最近命令
```

### Token 文件

- **路径**：`~/.apptracker/token`
- **格式**：base64url 编码的 32 字节随机数据
- **权限**：Unix 下 600
- **生成**：首次启动时自动生成

### 崩溃日志

- **路径**：`~/.active_tracker/crash.log`
- **格式**：追加写入，每次 panic 一个条目
- **内容**：时间戳、线程名、panic 信息、backtrace

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `RUST_LOG` | `tracker_core=info,apptracker=info` | 日志级别配置 |

### RUST_LOG 示例

```bash
# 默认
export RUST_LOG=tracker_core=info,apptracker=info

# 调试模式
export RUST_LOG=tracker_core=debug

# 仅错误
export RUST_LOG=tracker_core=error

# 模块级控制
export RUST_LOG=tracker_core::platform=debug,tracker_core=info
```

## AgentConfig 参数

```rust
pub struct AgentConfig {
    pub host: String,
    pub api_port: u16,
    pub no_activity: bool,
    pub no_capture: bool,
    pub capture_default_on: bool,
    pub poll_interval_ms: u64,
}
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `host` | String | `"127.0.0.1"` | API 绑定地址 |
| `api_port` | u16 | `5007` | API 端口（回退范围 5007-5012） |
| `no_activity` | bool | `false` | 禁用键鼠活动监听 |
| `no_capture` | bool | `false` | 禁用截图采集 |
| `capture_default_on` | bool | `false` | 截图默认开启 |
| `poll_interval_ms` | u64 | `250` | 窗口轮询间隔（毫秒） |

### 使用示例

```rust
// 默认配置
let handle = start_agent(AgentConfig::default()).await?;

// 自定义配置
let handle = start_agent(AgentConfig {
    host: "0.0.0.0".to_string(),  // 监听所有接口
    api_port: 8080,
    no_activity: true,             // 禁用键鼠监听
    capture_default_on: true,      // 截图默认开启
    ..Default::default()
}).await?;
```
