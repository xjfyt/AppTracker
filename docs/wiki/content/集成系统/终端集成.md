## 简介

终端集成检测当前窗口是否为终端应用，并提取其中运行的 Shell 进程和工作目录信息。支持 18 种终端模拟器和 15 种 Shell。

## 终端检测

### 检测逻辑

`detect_terminal()` 通过多维度匹配判断窗口是否为终端：

```mermaid
flowchart TD
    INPUT[WindowInfo] --> CHECK1{Bundle ID 匹配?}
    CHECK1 -->|是| FOUND[返回终端类型]
    CHECK1 -->|否| CHECK2{App Name 匹配?}
    CHECK2 -->|是| FOUND
    CHECK2 -->|否| CHECK3{可执行文件名匹配?}
    CHECK3 -->|是| FOUND
    CHECK3 -->|否| CHECK4{进程名匹配?}
    CHECK4 -->|是| FOUND
    CHECK4 -->|否| NONE[返回 None]
```

## 进程树遍历

### 算法

```mermaid
graph TD
    ROOT[终端进程 PID] --> REFRESH[sysinfo refresh_all]
    REFRESH --> DESCENDANTS[获取所有后代进程]
    DESCENDANTS --> CLASSIFY{分类}
    CLASSIFY -->|Shell 名称| SHELLS[Shell 列表]
    CLASSIFY -->|非黑名单| RUNNING[运行进程列表]
    CLASSIFY -->|黑名单| SKIP[跳过]
```

### 后代进程查找

```rust
fn descendants_of(system: &System, root: Pid) -> Vec<Pid> {
    let mut by_parent: HashMap<Pid, Vec<Pid>> = HashMap::new();
    for (pid, proc_) in system.processes() {
        if let Some(parent) = proc_.parent() {
            by_parent.entry(parent).or_default().push(*pid);
        }
    }
    // BFS 遍历
    let mut stack = vec![root];
    while let Some(parent) = stack.pop() {
        for child in by_parent.get(&parent) {
            if seen.insert(*child) { stack.push(*child); }
        }
    }
}
```

## Shell cwd 检测

### 优先级

```mermaid
flowchart TD
    SHELL_FILES[1. Shell 集成文件<br/>~/.active_tracker/shells/PID.cwd]
    PROC_CWD[2. 进程 cwd<br/>sysinfo Process.cwd]

    SHELL_FILES -->|有| USE_FILE[使用 shell_file cwd]
    SHELL_FILES -->|无| PROC_CWD
    PROC_CWD -->|有| USE_PROC[使用 process cwd]
    PROC_CWD -->|无| NONE[无 cwd]
```

### Shell 集成文件读取

```rust
pub fn read_shell_cwds() -> HashMap<u32, String> {
    let dir = home.join(".active_tracker").join("shells");
    for entry in fs::read_dir(dir) {
        let pid = entry.file_stem().parse::<u32>();
        // 检查进程是否仍存活
        if system.process(Pid::from_u32(pid)).is_none() {
            fs::remove_file(&path);  // 清理死进程的文件
            continue;
        }
        let cwd = fs::read_to_string(&path);
        out.insert(pid, cwd);
    }
}
```

## 命令行脱敏

### 脱敏规则

命令行参数中的敏感信息会被自动脱敏：

```rust
pub fn redact_cmdline(cmdline: &[String]) -> (Vec<String>, bool) {
    // 1. flag=value 格式: --password=secret -> --password=***
    // 2. flag value 格式: --token sk-xxx -> --token ***
    // 3. 已知模式: AKIA..., sk-..., ghp_..., xox...
}
```

### 脱敏示例

| 原始 | 脱敏后 |
|------|--------|
| `--password=super-secret-value` | `--password=sup***ue` |
| `--token sk-abcdefghijklmnopqrstuvwxyz` | `--token sk-***yz` |
| `AKIA1234567890ABCDEF` | `AKI***EF` |
| `ghp_abcdefghijklmnopqrstuvwxyz1234` | `ghp_***34` |

### 脱敏长度规则

| 长度 | 处理 |
|------|------|
| < 8 字符 | 不脱敏 |
| 8-12 字符 | 替换为 `***` |
| > 12 字符 | 保留前 3 后 2：`abc***xy` |
