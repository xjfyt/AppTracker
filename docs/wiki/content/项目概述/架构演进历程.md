## 简介

AppTracker 从最初名为 Active Tracker 的项目演变而来。本文档记录关键的架构变更和设计决策演进。

## Active Tracker 时期

项目最初以 Active Tracker 为名，主要特征：

- 配置目录：`~/.active_tracker/`
- Shell 集成写入：`~/.active_tracker/shells/<PID>.cwd`
- 崩溃日志：`~/.active_tracker/crash.log`

## AppTracker 重命名

重命名为 AppTracker 后，Token 存储路径迁移至 `~/.apptracker/token`。bridge.rs 中保留了向后兼容逻辑：

```rust
// ~/.apptracker/token 不存在时，尝试从 ~/.active_tracker/token 迁移
let legacy = home.join(".active_tracker").join("token");
if let Ok(raw) = fs::read_to_string(&legacy).await {
    let token = raw.trim().to_string();
    if !token.is_empty() {
        fs::write(&path, &token).await?;
        return Ok((path, token));
    }
}
```

Shell 集成脚本仍使用 `~/.active_tracker/shells/` 路径，保持向后兼容。

## 架构变更记录

### v0.1 -> v0.2：Tauri v2 迁移

- 从 Electron 迁移到 Tauri v2
- 前端从 React 简化为 vanilla HTML/CSS/JS
- 后端统一为 Rust（tracker-core crate）

### 文档追踪增强

- 添加 Office COM（Windows）和 AppleScript（macOS）文档检测
- 添加 UIA（Windows）和 AX（macOS）无障碍树遍历
- 添加 lsof（macOS）和 /proc/fd（Linux）文件描述符扫描
- 引入 DocumentMemory 标题-路径映射缓存

### 浏览器桥接

- 实现 MV3 Chrome/Firefox 扩展
- WebSocket 双向通信 + Token 鉴权
- 自动端口回退（5007-5012）

### Shell 集成

- 支持 bash/zsh/fish/pwsh/cmd 五类 Shell
- 通过 PROMPT_COMMAND / precmd / prompt function 写入 cwd 文件
- 自动清理已退出进程的 cwd 文件

## 当前架构状态

当前版本（v0.2）的架构稳定特征：

| 特征 | 状态 |
|------|------|
| Workspace 结构 | 2 crate（tracker-core + desktop/src-tauri） |
| API 服务器 | 单端口 Axum（REST + WS + SSE） |
| 平台支持 | Windows（Win32 + COM + UIA）、macOS（AppleScript + AX + lsof）、Linux（xdotool + /proc/fd + AT-SPI） |
| 浏览器支持 | Chrome/Edge/Brave/Arc/Firefox（MV3 扩展） |
| Shell 支持 | 18 种 Shell（bash/zsh/fish/pwsh/cmd/nu 等） |
| Feature Flags | activity（键鼠）、capture（截图） |
