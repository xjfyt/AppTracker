## Rust 代码规范

### 命名约定

| 元素 | 风格 | 示例 |
|------|------|------|
| 模块 | snake_case | `file_manager.rs`、`shell_files.rs` |
| 结构体 | PascalCase | `WindowInfo`、`ActivityStats` |
| 枚举 | PascalCase | `DocumentCategory` |
| 函数 | snake_case | `active_window`、`enrich_window` |
| 常量 | SCREAMING_SNAKE_CASE | `MAX_THUMB_SIZE`、`SHELL_NAMES` |
| 静态 | SCREAMING_SNAKE_CASE | `BORING_PATH_FRAGMENTS` |

### 序列化约定

所有面向 API 的结构体使用 serde camelCase：

```rust
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct WindowInfo {
    pub timestamp: f64,
    pub app_name: String,
    pub window_title: String,
    #[serde(rename = "windowId")]
    pub window_id: Option<String>,
    // ...
}
```

### 注释规范

- 模块级文档：`//!` 开头
- 函数文档：`///` 开头
- 内部注释：`//` 开头
- 复杂逻辑必须有注释说明原因

```rust
/// 与 [`foreground_match_key`] 的区别：不带 `window_title`。
/// 用于「这条 enrich 结果是不是还属于同一个窗口」的判断，避免标题抖动
/// 时富化结果被错判为过期。
fn window_identity_key(info: &WindowInfo) -> String { ... }
```

## JavaScript 代码规范

### 变量声明

使用 `const` 和 `let`，不使用 `var`：

```javascript
const DEFAULT_API_BASE = "http://127.0.0.1:5007";
let apiBase = document.querySelector("#apiBase").value;
```

### DOM 查询

缓存 DOM 元素引用：

```javascript
const statusEl = document.querySelector("#status");
const pauseBtn = document.querySelector("#pauseBtn");
```

### 事件处理

使用箭头函数：

```javascript
pauseBtn.addEventListener("click", async () => {
    paused = !paused;
    await fetch(`${apiBase}/api/v1/pause`, { ... });
});
```

### HTML 转义

所有用户输入必须转义：

```javascript
function escapeHtml(value) {
    return String(value).replace(/[&<>"']/g, (ch) => ({
        "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;",
    })[ch]);
}
```

## 模块组织

### tracker-core 模块结构

```
src/
├── lib.rs              # 模块声明 + 条件编译桩 + re-export
├── agent.rs            # 启动编排 + 窗口监控主循环
├── state.rs            # 共享状态
├── models.rs           # 数据结构
├── api/mod.rs          # HTTP/WS/SSE
├── activity.rs         # 键鼠监听
├── capture.rs          # 截图采集
├── bridge.rs           # Token 管理
├── tools.rs            # 工具函数
├── diagnostics.rs      # 诊断
├── integrations/
│   ├── mod.rs          # 富化管道编排
│   ├── file_manager.rs # 文件管理器
│   ├── terminal.rs     # 终端检测
│   ├── shell_files.rs  # Shell cwd 文件
│   └── linux_dbus.rs   # AT-SPI
└── platform/
    ├── mod.rs          # 平台抽象
    ├── windows.rs      # Windows 实现
    ├── macos.rs        # macOS 实现
    └── linux.rs        # Linux 实现
```

### 文件大小指导

- 单文件建议不超过 500 行
- 超过 500 行考虑拆分
- platform/ 下每个平台独立文件（允许较大）

## 错误处理规范

### 错误类型选择

| 场景 | 类型 |
|------|------|
| 可恢复的业务错误 | `anyhow::Result` + 日志 |
| 不可恢复的系统错误 | `panic`（由 supervised 捕获） |
| 平台 API 失败 | 返回 `None` 或空结果 |
| 超时 | kill 进程 + 返回 `None` |

### 错误日志级别

| 级别 | 场景 |
|------|------|
| `error!` | 任务 panic、系统故障 |
| `warn!` | 超时、权限问题、SSE lagged |
| `info!` | 启动完成、端口绑定 |
| `debug!` | 平台 API 查询失败、富化跳过 |
