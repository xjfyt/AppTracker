## 开发环境

### 必需工具

| 工具 | 版本 | 用途 |
|------|------|------|
| Rust | stable | 后端编译 |
| Node.js | 18+ | Tauri 开发服务器 |
| npm | 9+ | 前端依赖管理 |

### 平台额外依赖

| 平台 | 依赖 |
|------|------|
| Windows | Windows SDK，PowerShell 5.1+ |
| macOS | Xcode CLI Tools |
| Linux | xdotool, x11-utils, libdbus |

### IDE 推荐

- **Rust**：VS Code + rust-analyzer
- **前端**：VS Code（无额外插件需求）

## 常用命令

```bash
# 安装依赖
cd desktop && npm install

# 开发模式（Tauri + Vite）
npm run tauri dev

# 仅编译核心库
cd tracker-core && cargo build

# 运行测试
cd tracker-core && cargo test

# 检查代码
cd tracker-core && cargo clippy

# Release 构建
cd desktop && npm run tauri build
```
